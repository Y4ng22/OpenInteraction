# 前台委派测试集（Delegation）

测试实时前台模型的委派判断：简单请求自己回答，需要后台的请求发出委派事件，委派内容忠实于用户原意。不测通用工具调用，也不测改向和取消（那是委派之后的任务控制）。首个测试对象是 MiniCPM-o 4.5，数据本身与模型无关，之后作为 benchmark 扩充。

## 文件

| 文件 | 内容 |
| --- | --- |
| `cases.jsonl` | 200 条英文测试用例 |
| `synthesize.py` | 校验用例格式，并用 macOS `say` 合成 16 kHz 单声道 WAV |
| `audio/` | 合成结果和 `manifest.jsonl`，不提交，需要时重新生成 |
| `runners/` | 各前台模型的运行器，见 [`runners/README.md`](runners/README.md) |
| `score.py` | 评分，输出 `results/<run>.report.md` |
| `results/` | 各次运行的评分报告；原始预测不提交 |
| [`RESULTS.md`](RESULTS.md) | 结果汇总 |

```sh
cd experiments/delegation-bench
python3 synthesize.py --check   # 只校验
python3 synthesize.py           # 校验并合成到 audio/
```

## 用例构成

| 类别 | 条数 | 内容 |
| --- | --- | --- |
| `self` | 64 | 闲聊、稳定常识、简单计算、换算、翻译、建议、安慰、短创作、观点、小游戏、对话控制（停下、放慢、重复） |

## 字段

| 字段 | 说明 |
| --- | --- |
| `id` | `s`/`d`/`e` 加序号 |
| `category` | `self`、`delegate`、`edge`；非 edge 类与 `expected` 相同 |
| `subtype` | 细分类型，用于分析错误 |
| `scenario` | 使用场景，13 种，见上表 |
| `lang` | 语言代码，决定 TTS 声音；目前都是 `en` |
| `context` | 之前的对话轮次，以文本历史形式给模型，不合成语音 |
| `utterance` | 本轮用户语音的文字 |
| `expected` | `self`、`delegate`、`clarify` |
| `reference_objective` | 仅 `delegate` 有：忠实、自包含的任务描述，已消解指代 |
| `notes` | 标注理由或参考答案 |

## 标注规则

应委派（`delegate`）：
- 需要当前或实时信息：天气、新闻、价格、比分、汇率；
- 需要训练截止之后的信息；
- 需要检索或查找外部信息；
- 需要多步调研、对比，或长篇输出（报告、十条要点）；
- 需要对外操作：订位、下单、提醒、日历、邮件。

自己回答（`self`）：闲聊、稳定常识、简单计算、翻译、情感支持、简短创作、观点、对话控制。紧急情况（如 "I think I'm having a heart attack"）也是 `self`：前台应立刻让用户拨打 911，而不是开后台任务。

先澄清（`clarify`）：请求缺少对象且上下文里也没有，例如 "Can you look it up for me?"。

## 评分

- **委派判断**：以 `delegate` 为正类，算 precision / recall / F1；`self` 和 `clarify` 都算负类。
- **澄清**：`clarify` 条目另外人工判断是否提出了澄清问题。
- **格式**：发出的委派事件能否解析出 `objective`。
- **objective 忠实度**：对照 `reference_objective` 人工三档打分（忠实 / 有增删 / 错误），再算 BERTScore 作参考。
- **委派延迟**：语音结束到委派事件出现的时间。
- **稳定性**：每条跑 3 次，报告三次结果一致的比例。

## 离线与在线

| | 离线（先做） | 在线（之后） |
| --- | --- | --- |
| 运行方式 | 用 transformers 直接加载模型 | 走模型的实时双工服务（MiniCPM-o 为 WebSocket，端口 8006） |
| 输入 | 一段完整语音一次性输入，半双工 | 音频按流推送，模型自己决定何时开口 |
| 输出 | 一次完整的文本回复 | 流式语音加文本，委派事件要从流里实时解析 |
| 测什么 | 模型有没有委派能力：判断、格式、内容 | 部署行为：委派延迟、委派时是否同时在说话、标记会不会被念出、与 VAD 和打断的交互 |
| 资源 | 可把模型切到多张 16GB 卡上 | MiniCPM-o 官方要求单卡 40GB（推荐 48GB） |
| 复现性 | 可重复、可批量 | 受时序影响，不能完全复现 |

离线测不过，在线一定也不行，所以先做离线。

## 已知局限

- 音频为 TTS 合成，之后补录真人语音作对照。
- `clarify` 有 16 条，仍明显少于另外两类。
- 有些标注依赖时间（"今年"、"最近一届"），评分时以运行当天为准。
